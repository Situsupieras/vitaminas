## 💰 Regla de Kennedy (CAC Máximo)
-   **Margen por unidad (estimado)**:
    *   Precio de venta: Q299
    *   Costo estimado (producción, envío, etc.): Q100 (estimado)
    *   **Margen por unidad**: Q199
-   **LTV estimado (6 meses)**: Si compra el 3x2 (Q598) y luego se suscribe 3 meses (Q254.15 * 3 = Q762.45), el LTV podría ser Q598 + Q762.45 = Q1,360.45. O, si solo compra un frasco y luego se suscribe 3 meses = Q299 + Q762.45 = Q1061.45.
    *   Asumamos un LTV conservador de Q800 en 6 meses para un cliente que realiza una recompra.
-   **CAC Máximo**: Para ser rentable, nuestro CAC (Costo de Adquisición de Cliente) debería ser considerablemente menor que el Margen por unidad inicial y, idealmente, una fracción del LTV.
    *   **CAC Máximo para ser rentable en la primera compra**: Q199 (pero esto no deja margen para publicidad).
    *   **CAC Ideal (considerando LTV)**: Podemos invertir hasta un 30-50% del LTV para ser rentables a largo plazo. Así, un CAC de **Q240 - Q400** sería viable, ya que el valor de vida del cliente compensaría la inversión inicial. El objetivo es que el embudo pague el CAC en la primera compra o la primera recompra.
